# Five-day delivery plan

## Day 1

- Git monorepo and service layout
- Auth.js credentials login
- SQLite users, invites, conversations, audits and jobs
- Admin/examiner seed accounts
- Protected Next.js routes

## Day 2

- Admin PDF upload
- Global single-worker indexing queue
- Indexing status in the Next.js document library

## Day 3

- Claim extraction
- Numeric and citation verification
- Evidence-insufficient and contradiction verdicts
- JSON and printable audit report

## Day 4

- LAN access
- Reverse proxies for citation graph and PDF previews
- Thirty-case evaluation set
- Smoke, SSE and build tests

## Day 5

- Key rotation
- Demo account reset
- Final rehearsal
- Submission package
